## Ставьте мне звезды
Учусь, в профиле есть репозитории с разными языками, на которые можно ставить звезды. Некоторые состоят из нескольких небольших легких программ, также есть небольшие проекты. Большая часть программ на C++ (algoritms(САОД), OOP, comp_math, C-), простая программа на Java, также представлены приложения с графическим интерфейсом на WPF, логика на C#(ChatBot, 2048, DataBase). 
Fun fact: вы можете ставить звезды.
